# MERToolbox

## Uses

**MERToolbox** expands the capabilities of PMER, enabling you to create Doors, Clutter Objects, Cameras, Custom Items, and Lockers directly in the Unity Editor.

## How to Install
- Install the plugin `MERToolbox.dll` into `SCP Secret Laboratory/LabAPI/Plugins/Global|PORT`
- Install the Dependencies from the latest release or from [Dependencies](#dependencies) into `SCP Secret Laboratory/LabAPI/dependencies/Global|PORT`
- Install the `MERToolbox.unitypackage` into your SL-CustomObjects project.

## How to Compile from Unity

1. Add the MERToolBlocks component to your schematic root
2. Go to the MERToolbox tab and press compile
3. Get the compiled json from ``Desktop/MERToolbox_Compiled_Items``
4. Add the compiled json to ``SCP Secret Laboratory/LabAPI/configs/MERToolbox/UnityData``
